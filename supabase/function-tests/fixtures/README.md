# Function fixtures

`open-meteo-berlin.json` captures the hourly and 15-minute forecast for the public Berlin grid point 52.5°, 13.4° on 22 November 2026 UTC. Only the forecast series used by the app are retained. Open-Meteo supplies the data under CC BY 4.0. [Open-Meteo forecast API](https://open-meteo.com/en/docs)

`expo-tickets.json` follows the Expo documentation’s example of a mixed ticket response with test identifiers. [Expo push ticket example](https://docs.expo.dev/push-notifications/sending-notifications/#push-tickets)
