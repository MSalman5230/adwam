# Material Symbols Rounded

Run `node tools/icons/generate.mjs` from the repository root to regenerate the bundled paths. The generator reads the approved prototype's icon names, then takes the 24 dp rounded SVG paths from a pinned [Material Symbols revision](https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web). It includes the filled location icon and the three selected navigation icons. The app renders these paths with its theme colours.
